# Video Tutorials

Short demonstrations of **dicomqc Desktop**, recorded with version 0.2.0 and
using only synthetic repository fixtures.

[Watch the dicomqc tutorial playlist on YouTube](https://www.youtube.com/playlist?list=PLdDTb3FmPta0).

## Tutorials

| Video | What it shows |
| --- | --- |
| Overview | Why DICOM metadata needs an audit after de-identification, and how to navigate projects, runs, findings, and reports |
| Privacy audit | Load DICOM input, run the primary metadata audit, and review privacy findings and report files |
| Dataset comparison | Compare source and processed DICOM datasets using a pairing manifest, then inspect missing files and pseudonym consistency |

For written instructions, start with the [Desktop app](usage/desktop.md), then
follow the [privacy audit](usage/desktop-privacy.md) or
[dataset comparison](usage/desktop-comparison.md) example.
